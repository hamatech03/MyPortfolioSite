# Portfolio of Ichiro Hamasaki

React を中心に、フロントエンド技術の学習を目的として制作したポートフォリオサイトです。

## 使用技術・ライブラリ
- React
- Vite
- Node.js
- TypeScript
- react-router-dom
- react-bootstrap
- animate.css

## 制作過程で考えていたこと
- 過度に凝ったデザインを目指すのではなく、完成を優先するために React Bootstrap を採用しました。
- 制作を進める中で、Tailwind CSS や Material UI など、他の UI ライブラリにも興味を持つようになりました。
- 他者に見せることを前提としたプログラミング制作は本プロジェクトが初めてだったため、まずは「完成させること」を最優先に取り組みました。
- そのため、導入や運用の難易度が比較的低いライブラリを選定するよう意識しました。

## 課題点
- TypeScript の書き方や、React の基本的な Hooks、HTML / CSS など、基礎的な理解がまだ不十分だと感じています。
- 制作中は Google 検索や ChatGPT を活用していましたが、CSS の一部や useEffect の処理など、理解が難しい箇所については、ChatGPT に生成してもらったコードを参考にしつつ、そのまま使用した部分もあります。
- 今後も学習を継続し、CSS と React Hooks を中心に、仕組みの理解を深めたいと考えています。

## デプロイ後追記・・・

- 2026年1月25日、Vercelでデプロイを試みたところ、エラーが発生しデプロイに失敗しました。
- 原因は `pages` ディレクトリの `.tsx` ファイルをリネーム（小文字 → 大文字）した際、Git上で正しく反映されず、ファイルに差異が生じたことでした。ローカル環境では問題なく動作していましたが、本番環境でのみエラーが発生しました。
- 対応として、GitHubに別のリポジトリを作成し、本プロジェクトを改めてpushすることで解決しました。
- その後デプロイは成功しましたが、ページ遷移がうまくいかず、Vercelの404ページに遷移するエラーが発生しました。
- このエラーについては、以下の記事を参考に `vercel.json` を設定することで解決しました。
